# Introduction to Python & Data Science Tools

DataSci 217 is a practical introduction to the tools and reasoning used in
Python data work. The course moves from the command line and Python fundamentals
through NumPy, pandas, visualization, time series, modeling, and a complete
question-led analysis.

Lectures explain the ideas. Demos turn those ideas into executable worked
examples, and assignments provide independent practice.

## Course Format

- **Lectures** explain concepts and are presentation materials, not notebooks
  intended to be executed from top to bottom.
- **Demos** are executable worked examples. Most lectures use demonstrations near
  the first third, second third, and end of the material. Lecture 11 instead uses
  one extended project walkthrough.
- **Assignments** follow the lecture and demo progression. Each assignment
  directory is the source for a separate term repository. Assignment 11 is the
  larger take-home final and follows the capstone structure with a different
  dataset.

## Lectures

1. [Command Line + Python](/01/) — navigate the shell, manage files, run Python
   scripts, and set up VS Code.
2. [Python + Git](/02/) — use Python’s core data types, control flow, functions,
   files, and a GUI-first Git workflow.
3. [NumPy + Virtual Environments](/03/) — create and operate on arrays, select
   data, and isolate project dependencies.
4. [Jupyter + Pandas](/04/) — work with notebooks, Series, DataFrames, common
   file formats, types, missingness, and duplicate rows.
5. [Data Cleaning](/05/) — transform and validate data, clean strings, handle
   missing values, and reason about sampling design.
6. [Joins, Combining + Reshaping](/06/) — combine tables with explicit key and
   shape contracts, then move between wide and long forms.
7. [Data Visualization](/07/) — build effective plots with Matplotlib, pandas,
   Seaborn, and Altair.
8. [Aggregation + Group Operations](/08/) — summarize groups and choose among
   aggregation, transformation, filtering, and application.
9. [Time Series Analysis](/09/) — parse, index, shift, resample, and analyze
   observations over time.
10. [Statistics, Machine Learning + Deep Learning Models](/10/) — fit and compare
    models with leakage-aware preprocessing and evaluation.
11. [From Question to Defensible Result](/11/) — integrate the course around a
    focused question, clear provenance, appropriate evidence, and honest limits.
